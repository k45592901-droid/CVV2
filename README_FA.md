# بسته ساخت نسخه Portable برای Windows 11

## خروجی موردنظر
این پروژه برای ساخت خروجی `win-x64` به‌صورت Self-contained تنظیم شده است؛ روی سیستم مقصد به نصب .NET Runtime نیاز ندارد.

## وضعیت فعلی و محدودیت‌ها
- این پروژه فقط نمونه‌ی تشخیص متن (OCR) و نمایش متن شناخته‌شده را دارد.
- ترجمه‌ی آفلاین انگلیسی به فارسی و تشخیص گفتار هنوز در آن وجود ندارد.
- OCR فعلی از Windows.Media.Ocr استفاده می‌کند؛ برای تشخیص انگلیسی، قابلیت/بسته زبان انگلیسی ویندوز باید موجود باشد. بنابراین این نسخه هنوز «بدون هیچ پیش‌نیاز سیستمی» نیست.
- برای نسخه نهایی واقعاً مستقل باید OCR قابل‌حمل و مدل ترجمه EN→FA همراه برنامه بسته‌بندی و روی Windows 11 آزمایش شوند.

## ساخت خروجی بدون نصب ابزار روی کامپیوتر مقصد
ساده‌ترین راه این است که سورس را در GitHub قرار بدهی و GitHub Actions فایل ویندوزی را بسازد. برای این کار:
1. یک مخزن جدید در GitHub بساز.
2. تمام محتویات این پوشه را در مخزن بارگذاری کن.
3. از تب Actions، گردش‌کار `Build Windows Portable` را اجرا کن.
4. فایل `PersianTranslator-Portable` را از بخش Artifacts دانلود کن.

این روش هنوز برای ساخت به سرویس GitHub نیاز دارد، اما کامپیوتر مقصد نیازی به نصب .NET ندارد.

## ساخت مستقیم روی ویندوز
اگر .NET 8 SDK روی کامپیوتر سازنده نصب باشد، فایل `build-portable.bat` را اجرا کن. خروجی در پوشه `publish` قرار می‌گیرد.
